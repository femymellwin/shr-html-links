Your 2-Year AI & Data Science Certification Path

A practical, beginner-friendly plan for a third-year AI & Data Science student. Earn four relevant credentials, build real projects, and prepare for internships and full-time roles.

24 months 4 credentials ~10 hours/week Internship + placement ready

The 4-certification roadmap

Follow these in order, starting October 2026. Adjust dates around university exams and internship opportunities.

Months 1–6

  • Python, NumPy, pandas and scikit-learn
  • Regression, classification and neural networks
  • Project: Student performance predictor

Google Professional Certificate · Strengthen statistical analysis and data storytelling.

CERTIFICATION 03 • Oct 2027 – Mar 2028

AWS Certified AI Practitioner

Amazon Web Services · Understand AI, generative AI and responsible cloud AI.

  • AI and generative AI fundamentals
  • AWS AI services, security and governance
  • Project: Small document Q&A chatbot
Official certification
Months 19–24
CERTIFICATION 04 • Apr 2028 – Sep 2028

AWS Certified Machine Learning Engineer – Associate

Amazon Web Services · Develop practical skills for deploying and operating ML solutions.

  • Model training, deployment and monitoring
  • Data pipelines, MLOps and AWS services
  • Project: Deploy an ML model to the cloud
Official certification

Alongside the certifications

  1. Months 1–6: Build Python, SQL, Git and statistics fundamentals. Publish the first GitHub project.
  2. Months 7–12: Create one strong data analysis project. Apply for internships and participate in hackathons.
  3. Months 13–18: Learn basic cloud services, experiment with generative AI and practice coding interviews.
  4. Months 19–24: Focus on hands-on MLOps, a deployed capstone, mock interviews and placements.
